# 什么是BFC

Block Formatting Context区块格式化上下文，简称BFC。是Web页面的可视CSS渲染的一部分。是块级盒子布局过程中产生的区域，也是浮动元素与其他元素交互的区域

# 哪些方式会产生BFC

  • html
  • float: !none
  • position: absolute|fixed
  • display: inline-block|table-cell|table-caption|flow-root|flex|grid
  • overflow: !visible|!clip

格式化上下文会影响布局，通常会为了定位和清除浮动创建新的BFC，而不是更改布局，因为它将：

  • 包含内部浮动
  • 排除外部浮动
  • 阻止外边距重叠
