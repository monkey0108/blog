# Vue.js 中的组合式 API：从 Options API 到 Composition API 的全面解析

随着 Vue.js 3 的发布，组合式 API（Composition API）成为了开发者关注的焦点。相比于传统的 Options API，组合式 API 提供了更灵活、更强大的代码组织方式。本文将深入探讨 Vue.js 中的组合式 API，对比它与 Options API 的差异，并展示如何在实际项目中应用组合式 API。

# 1. 为什么需要组合式 API？

在传统的 Options API 中，组件的逻辑被分散到 data、methods、computed 等选项中，虽然易于上手，但在复杂组件中会面临以下问题：

  • 逻辑复用困难：相似的逻辑难以提取和复用。
  • 代码组织混乱：随着组件功能增加，代码变得难以维护。
  • 类型推断受限：在 TypeScript 中，类型推断不够友好。

组合式 API 通过将逻辑组织为函数，解决了这些问题，使得代码更具可读性、可维护性和可复用性。

# 2. 组合式 API 的核心概念

# 2.1 setup 函数

setup 是组合式 API 的入口函数，它在组件创建之前执行。setup 接收两个参数：

  • props：组件接收的 props。
  • context：包含 attrs、slots、emit 等属性。
<template>
  <p>{{ message }}</p>
  <button @click="increment">Click Me</button>
</template>

<script>
import { ref } from 'vue';

export default {
  setup() {
    const message = ref('Hello, Composition API!');
    const increment = () => {
      message.value = 'Button Clicked!';
    };

    return {
      message,
      increment,
    };
  },
};
</script>

# 2.2 响应式数据

组合式 API 提供了 ref 和 reactive 来创建响应式数据。

  • ref：用于创建单个响应式值。
  • reactive：用于创建响应式对象。
import { ref, reactive } from 'vue';

const count = ref(0); // 单个值
const state = reactive({ // 对象
  name: 'Vue',
  age: 3,
});

# 2.3 生命周期钩子

组合式 API 提供了对应的生命周期钩子函数。

import { onMounted, onUpdated, onUnmounted } from 'vue';

setup() {
  onMounted(() => {
    console.log('Component is mounted!');
  });

  onUpdated(() => {
    console.log('Component is updated!');
  });

  onUnmounted(() => {
    console.log('Component is unmounted!');
  });
}

# 3. 组合式 API 的高级用法

# 3.1 组合逻辑复用

通过自定义函数，可以将逻辑提取并复用。

// useCounter.js
import { ref } from 'vue';

export function useCounter() {
  const count = ref(0);
  const increment = () => count.value++;

  return {
    count,
    increment,
  };
}

// 在组件中使用
setup() {
  const { count, increment } = useCounter();
  return {
    count,
    increment,
  };
}

# 3.2 类型推导与 TypeScript 支持

组合式 API 对 TypeScript 的支持更加友好。

interface User {
  name: string;
  age: number;
}

const user = reactive<User>({
  name: 'Vue',
  age: 3,
});

# 4. 组合式 API 与 Options API 的对比

特性 Options API Composition API
逻辑组织 按选项分组 按逻辑功能分组
代码复用 通过 Mixins 或高阶组件复用 通过自定义函数复用
TypeScript 支持 支持，但类型推断较弱 原生支持，类型推导更强
学习曲线 简单，适合初学者 较陡，适合有经验的开发者
适用场景 小型应用或简单组件 复杂应用或需要复用的场景

# 5. 实际应用场景

# 5.1 复杂组件的逻辑拆分

在复杂组件中，使用组合式 API 将逻辑拆分为多个函数，使代码更清晰。

setup() {
  const { count, increment } = useCounter();
  const { user, fetchUser } = useUser();

  onMounted(() => {
    fetchUser();
  });

  return {
    count,
    increment,
    user,
  };
}

# 5.2 跨组件逻辑复用

通过自定义组合函数，实现跨组件的逻辑复用。

// useFetch.js
import { ref } from 'vue';

export function useFetch(url) {
  const data = ref(null);
  const error = ref(null);

  fetch(url)
    .then((res) => res.json())
    .then((json) => (data.value = json))
    .catch((err) => (error.value = err));

  return { data, error };
}

# 6. 总结

组合式 API 是 Vue.js 3 的重要特性，它为开发者提供了更灵活、更强大的代码组织方式。对于复杂应用或需要逻辑复用的场景，组合式 API 是一个理想的选择。如果你还没有尝试过，建议从简单的组件开始，逐步掌握其用法。
