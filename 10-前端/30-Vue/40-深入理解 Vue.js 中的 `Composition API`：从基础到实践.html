# 深入理解 Vue.js 中的 Composition API：从基础到实践

Vue 3.x 引入了 Composition API，这是对 Options API 的一次重大升级。Composition API 提供了更灵活、更强大的方式来组织和复用代码逻辑。本文将深入探讨 Composition API 的核心概念和实际应用，帮助你掌握这一现代前端开发的利器。

# 1. 为什么需要 Composition API？

在 Vue 2.x 中，Options API 是主要的代码组织方式，但随着应用复杂度的提升，Options API 暴露出一些问题：

  • 逻辑分散：相关代码被拆分到 data、methods、computed 等选项中，导致难以维护。
  • 复用困难：逻辑复用的主要手段是 mixins，但 mixins 容易引发命名冲突和代码耦合。

Composition API 通过将逻辑组织到函数中，解决了上述问题，提供了更好的代码组织和复用能力。

# 2. Composition API 的核心概念

# 2.1 setup 函数

setup 是 Composition API 的核心入口，它在组件实例创建之前执行，接收 props 和 context 作为参数。

import { ref } from 'vue';

export default {
  setup(props, context) {
    const count = ref(0);

    function increment() {
      count.value++;
    }

    return {
      count,
      increment,
    };
  },
};

注意：setup 中不能使用 this，因为组件实例尚未创建。

# 2.2 ref 和 reactive

ref 和 reactive 是两种创建响应式数据的方式：

  • ref：适合基本类型数据，通过 .value 访问和修改。
  • reactive：适合对象或数组，直接访问和修改属性。
import { ref, reactive } from 'vue';

const count = ref(0);
const user = reactive({ name: 'Vue', age: 3 });

# 2.3 computed 和 watch

  • computed：创建计算属性，依赖变化时自动重新计算。
  • watch：监听响应式数据的变化，执行副作用逻辑。
import { computed, watch } from 'vue';

const doubleCount = computed(() => count.value * 2);

watch(count, (newVal, oldVal) => {
  console.log(`Count changed: ${oldVal} -> ${newVal}`);
});

# 3. Composition API 的实践技巧

# 3.1 逻辑复用：自定义 Hook

通过将逻辑封装到自定义 Hook 中，可以轻松实现代码复用。

// useCounter.js
import { ref } from 'vue';

export function useCounter() {
  const count = ref(0);

  function increment() {
    count.value++;
  }

  return {
    count,
    increment,
  };
}

// 在组件中使用
import { useCounter } from './useCounter';

export default {
  setup() {
    const { count, increment } = useCounter();
    return {
      count,
      increment,
    };
  },
};

# 3.2 组合逻辑：多个 Hook 的协作

在复杂组件中，可以组合多个 Hook 来实现功能。

import { useCounter, useUser } from './hooks';

export default {
  setup() {
    const { count, increment } = useCounter();
    const { user, updateUser } = useUser();

    return {
      count,
      increment,
      user,
      updateUser,
    };
  },
};

# 3.3 结合 provide 和 inject

通过 provide 和 inject，可以轻松实现跨组件的数据传递。

// 父组件
import { provide, ref } from 'vue';

export default {
  setup() {
    const theme = ref('dark');
    provide('theme', theme);
  },
};

// 子组件
import { inject } from 'vue';

export default {
  setup() {
    const theme = inject('theme');
    return {
      theme,
    };
  },
};

# 4. Composition API 与 Options API 的对比

特性 Composition API Options API
代码组织 基于函数逻辑组织 基于选项 (data, methods)
复用性 高，通过自定义 Hook 实现 中低，依赖 mixins
TypeScript 支持 优秀，天然支持 TypeScript 一般，需要额外配置
学习曲线 较高，需要理解响应式原理和 Hook 较低，适合初学者

# 5. 总结

Composition API 是 Vue.js 生态中的一次重要进化，它提供了更灵活、更强大的方式来组织和复用代码逻辑。无论是小型项目还是大型应用，Composition API 都能显著提升开发效率和代码质量。

通过掌握 setup、ref、reactive 等核心概念，并结合自定义 Hook 等实践技巧，你可以充分发挥 Composition API 的潜力，编写出更优雅的 Vue.js 代码。
