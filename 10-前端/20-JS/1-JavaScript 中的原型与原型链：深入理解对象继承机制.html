# JavaScript 中的原型与原型链：深入理解对象继承机制

JavaScript 是一门基于原型的语言，理解原型和原型链是掌握 JavaScript 对象继承机制的关键。本文将深入探讨 JavaScript 中的原型与原型链，帮助你彻底理解对象之间的关系以及继承的实现方式。

# 1. 什么是原型？

在 JavaScript 中，每个对象都有一个内部属性 [[Prototype]]，指向它的原型对象。原型对象也是一个普通对象，它包含可以被其他对象共享的属性和方法。

# 1.1 访问原型

可以通过以下方式访问一个对象的原型：

# 1.1.1 __proto__ 属性

__proto__ 是一个非标准的属性，但它被大多数浏览器支持，用于访问对象的原型。

const obj = {};
console.log(obj.__proto__); // 输出: Object.prototype

# 1.1.2 Object.getPrototypeOf()

Object.getPrototypeOf() 是标准的获取对象原型的方法。

const obj = {};
console.log(Object.getPrototypeOf(obj)); // 输出: Object.prototype

# 1.2 设置原型

可以通过以下方式设置一个对象的原型：

# 1.2.1 Object.create()

Object.create() 用于创建一个新对象，并指定其原型。

const parent = { name: 'Parent' };
const child = Object.create(parent);

console.log(child.name); // 输出: Parent
console.log(Object.getPrototypeOf(child) === parent); // 输出: true

# 1.2.2 Object.setPrototypeOf()

Object.setPrototypeOf() 用于设置一个对象的原型。

const parent = { name: 'Parent' };
const child = {};
Object.setPrototypeOf(child, parent);

console.log(child.name); // 输出: Parent
console.log(Object.getPrototypeOf(child) === parent); // 输出: true

# 2. 什么是原型链？

原型链是一种查找属性的机制。当访问一个对象的属性时，JavaScript 引擎会按照以下顺序查找：

  1. 对象自身属性。
  2. 对象的原型。
  3. 原型的原型，直到 Object.prototype。
  4. 如果找到 null，则返回 undefined。
const grandparent = { name: 'Grandparent' };
const parent = Object.create(grandparent);
const child = Object.create(parent);

console.log(child.name); // 输出: Grandparent

在这个例子中，child 对象自身没有 name 属性，于是 JavaScript 引擎会沿着原型链查找：

  • child 的原型是 parent。
  • parent 的原型是 grandparent。
  • grandparent 拥有 name 属性，因此返回 'Grandparent'。

# 3. 构造函数与原型

# 3.1 构造函数

构造函数是用于创建对象的函数。使用 new 关键字调用构造函数时，会创建一个新对象，并将该对象的原型指向构造函数的 prototype 属性。

function Person(name) {
  this.name = name;
}

const person = new Person('Alice');
console.log(person.name); // 输出: Alice

# 3.2 构造函数的 prototype

每个构造函数都有一个 prototype 属性，指向一个对象。所有通过该构造函数创建的对象都会共享 prototype 上的属性和方法。

Person.prototype.greet = function() {
  console.log('Hello, ' + this.name);
};

person.greet(); // 输出: Hello, Alice

# 4. 继承的实现

# 4.1 原型链继承

通过将子类的原型指向父类的实例，实现继承。

function Animal(name) {
  this.name = name;
}

Animal.prototype.speak = function() {
  console.log(this.name + ' makes a noise.');
};

function Dog(name) {
  Animal.call(this, name);
}

Dog.prototype = Object.create(Animal.prototype);
Dog.prototype.constructor = Dog;

const dog = new Dog('Buddy');
dog.speak(); // 输出: Buddy makes a noise.

# 4.2 class 语法

ES6 引入了 class 语法，提供了更简洁的继承实现。

class Animal {
  constructor(name) {
    this.name = name;
  }

  speak() {
    console.log(this.name + ' makes a noise.');
  }
}

class Dog extends Animal {
  constructor(name) {
    super(name);
  }

  bark() {
    console.log(this.name + ' barks.');
  }
}

const dog = new Dog('Buddy');
dog.speak(); // 输出: Buddy makes a noise.
dog.bark(); // 输出: Buddy barks.

# 5. 原型与原型链的应用场景

# 5.1 共享方法

通过原型共享方法，可以节省内存空间。

function Person(name) {
  this.name = name;
}

Person.prototype.sayHello = function() {
  console.log('Hello, ' + this.name);
};

const person1 = new Person('Alice');
const person2 = new Person('Bob');

person1.sayHello(); // 输出: Hello, Alice
person2.sayHello(); // 输出: Hello, Bob

# 5.2 动态扩展功能

可以通过修改原型动态扩展对象的功能。

const arr = [1, 2, 3];

Array.prototype.sum = function() {
  return this.reduce((acc, val) => acc + val, 0);
};

console.log(arr.sum()); // 输出: 6

# 6. 总结

原型和原型链是 JavaScript 的核心概念，理解它们对于掌握对象继承和属性查找机制至关重要。通过原型链，JavaScript 实现了强大的继承功能，而 class 语法则提供了更现代和简洁的继承方式。
