# 高阶函数

# 什么是高阶函数

js中函数可以作为参数和返回值，高阶函数至少满足一个条件

  • 参数是一个或者多个函数
  • 返回是函数

# 案例

  • 数组操作（filter、sort、map...）
  • 模版引擎
  • 防抖、节流
  • React Redux的connect函数

# 高阶组件

# 什么是高阶组件

其接受一个组件返回一个装饰过的组件

# 案例

HOC函数

function wrapWidthUserName(Component) {
  const username = '张三'
  return function (props) {
    return <Component username={username}/>
  }
}

组件A

function ComponentA(props) {
  return (
    <div>
      <p>组件A</p>
      <p>{props.username}</p>
    </div>
  )
}
export default wrapWidthUserName(ComponentA)

组件B

function ComponentB(props) {
  return (
    <div>
      <p>组件B</p>
      <p>{props.username}</p>
    </div>
  )
}
export default wrapWidthUserName(ComponentB)
