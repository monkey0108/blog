# 克隆源码

从github克隆stable-diffusion-webui代码到本地

这里下载太慢，我使用的是GitCode的镜像仓库地址 https://gitcode.net/mirrors/C43H66N12O12S2/stable-diffusion-webui.git

# 安装Python环境

brew install pyenv // 安装Python版本管理工具
pyenv install 3.10.4 // 安装Python
pyenv global 3.10.4 // 全局设置Python版本
pyenv local 3.10.4 // 本地目录设置Python版本

# 配置git加速地址

stable-diffusion-webui/modules/launch_utils.py

prepare_environment方法 https://github.com 替换成 https://ghproxy.com/https://github.com

# 执行webui.sh

cd stable-diffusion-webui
./webui.sh
